# Stash

Interactive prototype of **Stash**, a mobile app for tracking movies, series, games, anime and books in one place, with recommendations from your own ratings and friend profiles.

Open `index.html` in a browser, or publish it with GitHub Pages. On a desktop the app is shown inside a phone frame; on a phone it fills the screen.

## What you can try

- **Home**: trending carousel, Continue (progress), "Because you loved…" picks and top picks from friends. Filter by type with the chips.
- **Details**: tap any poster. Set status (Want / In progress / Done / Dropped), step progress forward, read reviews.
- **Rate it**: score slider, up to two feelings, written thoughts.
- **Discover**: search, browse by type, and Roulette (swipe right to save, left to skip).
- **Library, Friends, Profile**: your stash by status, taste match and leaderboard, stats and genre taste.

Recommendations are computed without AI: genre overlap with titles you rated 8 or higher, plus how many friends recommend a title.

All titles, posters and people are made-up example data. Changes are saved in the browser's localStorage only.
